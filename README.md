# 터 — 사주 × 주거 입지 비교 데모

- [최신 앱](https://ojt-next.github.io/saju-home-demo/)
- [29개 버전 목록](https://ojt-next.github.io/saju-home-demo/versions/)

이 저장소는 사주 웹사이트의 공개용 실행 파일만 관리합니다. 개인 자료, 인증 정보, 고객 입력, 다른 프로젝트는 포함하지 않습니다.

## 버전 기록

원본 Git의 태그(있는 경우) 또는 package.json 버전 변경 커밋으로 2026-10-12에 재빌드했습니다. 과거 배포 파일의 원본 보관본은 아닙니다. 각 versions/v*/version.json에 원본 커밋, 재빌드 날짜, 검증 범위가 있습니다. GitHub Pages에서 열 수 있도록 상대 자산 경로(--base ./)만 적용했습니다. 모든 버전의 타입 검사, 해당 시점 테스트, 빌드와 로컬 파일 참조를 확인했습니다. 전체 버전의 모든 화면 흐름을 수동 검증한 것은 아닙니다.

각 v* 태그는 해당 버전을 추가한 이 데모 저장소의 커밋을 가리킵니다. 원본 소스 저장소의 커밋과 구분합니다. 기본 주소는 v0.13.0의 핵심 MVP입니다. 이전 28개 버전은 각각의 주소에서 보존합니다.

## 사용 범위

명식·방위·환경 비교는 전문가 검토 전 프로토타입입니다. 이전 버전의 세금·비용 기준은 과거 상태이며 현재 기준을 보장하지 않습니다. 입력은 브라우저에서 처리하며 최신 버전의 저장은 사용자가 선택할 때만 브라우저에 보관합니다.

THIRD_PARTY_NOTICES.txt 및 각 버전 폴더의 고지 파일을 함께 보존합니다.

## v0.11.0 서울 구 탐색

서울 25개 구를 복수 오행 태그로 필터하고 기존 후보 등록으로 연결합니다. 자료 확인일은 2026-10-12이며 사주명리의 2024-10-08 분류표와 사주 fyi의 구별 분류를 참조합니다. 원문 문장과 이미지는 복제하지 않습니다. 출처 링크와 민간 상징 분류의 한계는 앱에서 펼쳐볼 수 있습니다. 개인 참고는 기존 일간 상생 규칙이며 부족 오행이나 용신을 판단하지 않습니다. 좌표·환경·가격은 구 태그에서 추정하지 않습니다.

## v0.12.0 오픈소스 지도

Leaflet 1.9.4 및 southkorea/seoul-maps의 JUSO 2015 구 경계(geometry 변경 없음)를 사용하고 오행 색·복수 태그 줄무늬·구 선택을 튜닝했습니다. 외부 지도 타일이나 API는 사용하지 않습니다. 지도 고지는 SEOUL_MAP_LICENSE.txt, Leaflet 고지는 THIRD_PARTY_NOTICES.txt에 보존합니다. 출처와 상세 근거는 데이터·보고서에 유지하고 기본 화면에서는 접었습니다. 지도는 지역 탐색용이며 실제 매물 검색이나 주소 판정 기능은 아닙니다.

## v0.13.0 핵심 MVP

양력 생일→서울 관심 구→집 후보 최대 3곳→공원·지역 태그·방향·기본 비용 비교. 상세 명식/근거·가족·달력·보고서 화면은 최신 MVP에서 제공하지 않습니다. 공원은 집 후보에 검색 또는 직접 입력으로 연결하며 지도/거리 측정은 없습니다. 방향은 구 중심끼리의 근사이며 실제 집 방향과 다를 수 있습니다.

실제 Daangn Seed React/CSS 3.0.0을 사용합니다. 본문/입력 16px, 보조 14px, 버튼 최소 48px·입력 52px. Microsoft Fluent Emoji 3D 7종은 로컬 자산으로 포함하며 fluent-emoji/LICENSE.txt와 manifest.json에 MIT 고지와 원본 리비전/해시를 보존합니다. 별도 MVP 키로 선택 저장하고 기존 버전 저장을 변경하지 않습니다. 174테스트·타입 검사·빌드 및 모바일 CSS 320/390px 확인.
